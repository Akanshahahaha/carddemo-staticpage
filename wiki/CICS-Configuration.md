## Overview

CardDemo requires various CICS resources to be defined and installed. This guide covers all resource definitions needed for the base application and optional modules.

### Resource Definition Methods

**DFHCSDUP (Recommended)**
- Batch utility for resource definition
- Reproducible and scriptable
- Provided in CSD folder

**CEDA (Interactive)**
- Online resource definition
- Immediate feedback
- Good for testing and troubleshooting

**RDO (Resource Definition Online)**
- Modern CICS resource definition
- Recommended for CICS TS 5.x+

## Resource Groups

### Base Application Group

All CardDemo resources are defined in the CARDDEMO group:

```
CEDA DEFINE GROUP(CARDDEMO) DESCRIPTION('CardDemo Application Resources')
```

### Resource Categories

- **Programs**: 29 online programs
- **Transactions**: 14 transactions
- **Files**: 10 VSAM files
- **Mapsets**: 14 BMS mapsets

## Installation Methods

### Method 1: DFHCSDUP (Batch)

Use the provided DFHCSDUP job in the CSD folder:

```jcl
//CSDUP    EXEC PGM=DFHCSDUP
//STEPLIB  DD DSN=CICS.SDFHLOAD,DISP=SHR
//DFHCSD   DD DSN=CICS.DFHCSD,DISP=SHR
//SYSPRINT DD SYSOUT=*
//SYSIN    DD *
  DEFINE GROUP(CARDDEMO) AS(...)
  [All resource definitions]
  INSTALL GROUP(CARDDEMO)
/*
```

### Method 2: CEDA (Interactive)

Execute CEDA commands interactively:

```
CEDA
DEFINE GROUP(CARDDEMO)
DEFINE PROGRAM(...) GROUP(CARDDEMO)
[Continue with all definitions]
INSTALL GROUP(CARDDEMO)
```

### Method 3: Batch CEDA

Create a batch job with CEDA commands:

```jcl
//CEDA     EXEC PGM=DFHCSDUP
//STEPLIB  DD DSN=CICS.SDFHLOAD,DISP=SHR
//DFHCSD   DD DSN=CICS.DFHCSD,DISP=SHR
//SYSPRINT DD SYSOUT=*
//SYSIN    DD *
  CEDA DEFINE GROUP(CARDDEMO)
  CEDA DEFINE PROGRAM(COSGN00C) GROUP(CARDDEMO) ...
  [All definitions]
  CEDA INSTALL GROUP(CARDDEMO)
/*
```

## Verification

### Verify Resource Installation

**Check Group:**
```
CEMT INQUIRE GROUP(CARDDEMO)
```

**Check Programs:**
```
CEMT INQUIRE PROGRAM(COSGN00C)
CEMT INQUIRE PROGRAM(COACTVWC)
```

**Check Transactions:**
```
CEMT INQUIRE TRANSACTION(CC00)
CEMT INQUIRE TRANSACTION(CAVW)
```

**Check Files:**
```
CEMT INQUIRE FILE(ACCTDAT)
CEMT INQUIRE FILE(CARDDAT)
```

**Check Mapsets:**
```
CEMT INQUIRE MAPSET(COSGN00)
```

### Test Access

**Test Sign-On:**
```
Clear screen
Enter: CC00
Should display sign-on screen
```

**Test File Access:**
```
CEMT SET FILE(ACCTDAT) OPEN
CEMT INQUIRE FILE(ACCTDAT)
Should show OPEN status
```

### Common Verification Issues

**Issue: Resource not found**
- Verify resource is defined: `CEDA VIEW GROUP(CARDDEMO)`
- Install if not installed: `CEDA INSTALL GROUP(CARDDEMO)`

**Issue: Program not found**
- Check load library in DFHRPL
- Verify program compiled successfully
- Execute NEWCOPY if needed

**Issue: File not open**
- Open file: `CEMT SET FILE(ACCTDAT) OPEN`
- Check VSAM file exists and is cataloged
