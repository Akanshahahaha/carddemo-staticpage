    How to Use This Wiki

    For First-Time Users

    1. Start with Home to understand what CardDemo is
    2. Follow the Quick Start for rapid installation
    3. Read the User Guide to learn how to use the application
    4. Refer to Troubleshooting if you encounter issues

    For Administrators

    1. Review Architecture to understand the system design
    2. Follow the Installation Guide for complete setup
    3. Study the Admin Guide for administrative tasks
    4. Configure CICS using CICS Configuration
    5. Set up batch processing with Batch Processing

    For Developers

    1. Understand the Architecture
    2. Review Technical Components
    3. Study Data Models
    4. Read Contributing before making changes
    5. Use Glossary for terminology reference

    For Modernization Projects

    1. Analyze Architecture for system understanding
    2. Review Technical Components for inventory
    3. Study Data Models for data migration planning
    4. Examine optional modules for integration patterns
    5. Use as a reference application for testing migration tools

    Key Features Documented

    Base Application

    • 29 COBOL Programs - Complete online transaction processing
    • 33 JCL Jobs - Comprehensive batch processing
    • 14 Transactions - Full user and admin functionality
    • 10 VSAM Files - Complete data management
    • 14 BMS Maps - All screen definitions

    Optional Modules

    • IMS-DB2-MQ Authorization - Real-time authorization with multiple databases
    • DB2 Transaction Types - Relational database integration
    • VSAM-MQ Extraction - Message queuing integration

    Technologies Covered

    • Assembler utilities
