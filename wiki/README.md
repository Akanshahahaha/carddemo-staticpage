## Key Features Documented

### Base Application
- **29 COBOL Programs** - Complete online transaction processing
- **33 JCL Jobs** - Comprehensive batch processing
- **14 Transactions** - Full user and admin functionality
- **10 VSAM Files** - Complete data management
- **14 BMS Maps** - All screen definitions

### Optional Modules
- **IMS-DB2-MQ Authorization** - Real-time authorization with multiple databases
- **DB2 Transaction Types** - Relational database integration
- **VSAM-MQ Extraction** - Message queuing integration

### Technologies Covered
- COBOL programming
- CICS transaction processing
- VSAM file management
- JCL batch processing
- BMS screen design
- DB2 relational database
- IMS hierarchical database
- IBM MQ messaging
- Assembler utilities
